## Contacting RCC

The quickest way to get help with problems, questions, concerns, etc is to contact RCC Support with an email to:

rcc-support@uq.edu.au

For more complicated questions and problem, or where a back and forth of emails would be required, RCC Support will ask users to attend one of RCC Support's drop in sessions, see [below](#getting-hands-on-help)


## Getting hands-on help

RCC can assist with specific software or HPC usage issues through two weekly meetups that are run via Zoom (changing to teams in 2027).

- [Hacky Hour UQ 1-2pm Tuesdays](https://rcc.uq.edu.au/training-support/meetups#Hacky%20Hour%20UQ%C2%A0%C2%A0)<br>
Members of the RCC Support team, the Data Science team, and the Library are available to help. <br>
They can advise on getting started on Bunya and running jobs on Bunya in general, software and data installations, questions around UQRDM, etc. They can offer to look at code, runtime errors, and how to use domain specific software, but help there might be limited. <br>
Specific domain expertise includes, VASP and other density functional software to a lesser extent, CryoSparc, major bioinformatics packages, containers, R.
 

- [Virtual HPC Support 09:30-10:30 Thursdays](https://rcc.uq.edu.au/training-support/meetups#vHPC) <br>
Members of the RCC Support team only are available to help.<br> 
This meetup is primarily about HPC usage and not for specialised help with genomics tools, software packages or programming languages. The RCC Support members can, however, help with generalities of finding and activating software packages and using languages in the HPC environment.

## Escalating concerns or complaints which will be treated confidentially

Concerns or complaints can be escalated by contacting

director@rcc.uq.edu.au

Concerns or complaints submitted to the RCC director will be treated confidentially.

These can include concerns/complaints about RCC staff, handling of user tickets, and user support in general.

Complaints that are technical in nature, Bunya hardware, software, and setup, should where possible be directed to RCC Support (rcc-support@uq.edu.au).
